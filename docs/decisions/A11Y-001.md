# A11Y-001: Accessibility implementation target

**Status:** Complete for the validated standalone report artifact
**Date:** 2026-09-13  
**Owner:** Dipuraj Thapa  
**Target:** WCAG 2.2 Level AA

## Implemented report requirements

- Language, unique title, one H1 and semantic header/main/footer landmarks.
- Keyboard-visible skip link and focus indicators.
- Native data table with caption and scoped row/column headers.
- Keyboard-focusable labeled region for horizontally scrollable tables.
- Text labels for gates and statuses; color is supplementary only.
- Relative typography, user zoom support and compatibility with user text-spacing overrides.
- Single-column reflow below 37.5rem with no page-level required horizontal scrolling.
- High-contrast preference and print support.
- No remote fonts, scripts, CDNs, hover-only content, animation or custom widgets.
- Escaping of every dynamic value rendered in the report.

## Traceable requirements

- `A11Y-REQ-001`: semantic structure, accessible names, table relationships and text status.
- `A11Y-REQ-002`: AA text contrast, zoom/reflow, forced-colors and text-spacing compatibility.
- `A11Y-REQ-003`: Chromium and Firefox automated viewport, focus, console and network checks.
- `A11Y-REQ-004`: human NVDA/Chrome and Narrator/Edge validation bound to the exact report hash.

Tests `A11Y-AUTO-001` through `A11Y-AUTO-004` cover structural, palette, responsive and
cross-browser behavior. Tests `A11Y-EVD-001` through `A11Y-EVD-003` enforce complete, passing,
hash-bound human evidence. Manual cases `A11Y-MAN-001` through `A11Y-MAN-010` are defined in the
human protocol.

Acceptance criteria:

- `A11Y-AC-001`: automated semantics and textual-status tests pass.
- `A11Y-AC-002`: contrast and cross-browser responsive/enhanced-mode checks pass.
- `A11Y-AC-003`: both required screen-reader environments pass all ten manual cases.
- `A11Y-AC-004`: validated evidence names the exact report SHA-256 and tool versions.

## Evidence and claim boundary

Automated structural tests cover semantics, labels, focus rules, textual status, reflow CSS,
offline behavior, escaping and zoom compatibility. GitHub Actions run `34777798680` additionally
passes Chromium and Firefox at 320, 375, 768 and 1440 CSS pixels plus a forced-colors/text-spacing
mode, with keyboard navigation, overflow, console and network assertions. The target follows WCAG
2.2 AA, but no formal conformance claim is authorized until the human screen-reader/manual protocol
is executed and recorded on the final release artifact.

# GHA-001: GitHub Actions activation

**Status:** Active  
**Date:** 2026-09-13  
**Owner:** Dipuraj Thapa  
**Target:** Core baseline continuous verification

## Decision

Run read-only core and browser-verification jobs on pushes to `main`, pull requests, and manual
dispatch. The Python job executes lint and tests, builds the wheel, installs it in a clean
environment, and retains it for 14 days. The dependent browser job installs isolated Chromium and
Firefox runtimes, verifies the generated offline report and retains its evidence for 14 days.

## Boundaries

- No provider credentials or repository secrets are required.
- Workflow permissions are `contents: read`.
- GitHub Actions verifies the repository build only. It does not verify Stripe, Supabase, remote targets, accessibility conformance, or cPanel.
- Official actions are pinned to immutable commit SHAs. Dependabot checks monthly for action updates.
- A failed or unavailable job blocks only the CI verification claim. It does not convert a reference result into a product finding.

## Failure and recovery

The workflow preserves any built wheel even when a later step fails. A failed run is rerun only after inspecting its logs; no test result is changed or suppressed. Rollback is removal/reversion of `.github/workflows/ci.yml`, which does not affect core runtime behavior.

## Acceptance

1. The workflow starts on `main` and pull-request changes.
2. It passes lint, tests, wheel build, clean install, version, and help checks on Python 3.11.
3. It publishes the wheel artifact without requiring secrets.
4. Repository results never imply external-provider verification.
5. Chromium and Firefox report matrices publish JSON measurements and screenshots without making
   a formal accessibility-conformance claim.
